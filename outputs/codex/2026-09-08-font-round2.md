## 2. Type scale, applied

### Implementation conventions

Every tuple below is:

**`family / fontSize / weight / lineHeight / letterSpacing`**

- `D` = `FONT_DISPLAY`.
- `R` = `FONT_DISPLAY_REGULAR`.
- `M` = `FONT_DISPLAY_MEDIUM`.
- `S` = system font: omit `fontFamily`; do not write `"SF Pro"`.
- `auto` = omit `lineHeight`.
- Weight shown for a display family is its **baked asset weight**. Do not add `fontWeight` to display text.
- For system text, write the specified `fontWeight` string.
- Current omitted sans weights/tracking are recorded as their ordinary defaults: `400` and `0`.
- All sizes and line heights are **pre-scale values**. In tables marked **scaled**, use `scaleFontSize(value)` for both. In tables marked **raw**, retain the file’s existing unscaled approach.
- Letter spacing and layout spacing remain raw logical units; never wrap them in `scaleFontSize`.
- Preserve colors, alignment, state decorations, and other properties unless explicitly changed below.
- Modifier styles receive only the stated override; their remaining values continue to inherit from the base style.

This is a semantic adjustment as well as a font replacement: **user-entered reminder titles and operational card text become system sans.** The editable title is an input, not a screen heading.
