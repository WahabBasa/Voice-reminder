# VoiceReminder legal pages

1. Create a **public** GitHub repo named `voicereminder-legal` (no README, no .gitignore).
2. Push the **contents** of this folder (not the folder itself) to `main`: `index.html`, `privacy.html`, `terms.html`, `style.css`.
3. In the repo: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/ (root)` → Save**.
4. Wait ~1 minute, then check `https://wahabbasa.github.io/voicereminder-legal/` — privacy is at `/privacy.html`, terms at `/terms.html`.
5. Use those two URLs in App Store Connect (Privacy Policy URL), in the app's Settings screen, and on the paywall footer.
