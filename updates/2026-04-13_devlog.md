# Devlog - 2026-04-13

## UI polish, permission prompt, reminder scheduling fix, OpenRouter switch - (07:17)

**Status**: ✅ Release APK on device, reminders firing correctly

Big session. Fixed the release build, overhauled settings UI, added a permission prompt, fixed a critical bug where reminders never fired, and switched LLM parsing from OpenAI to OpenRouter.

**Release build fix** — `@babel/plugin-transform-dynamic-import` was running on all builds, converting `import()` to `require()`. Metro handles dynamic imports natively, so release builds crashed on launch (white screen). Restricted the plugin to test-only in `babel.config.js`. Also discovered that `CI=true --no-daemon` is required on Windows to avoid `kill EPERM` from jest-worker cleanup.

**Settings redesign** — Replaced individual grey rows with grouped white cards, hairline separators, and better visual hierarchy. Pro upgrade card is more prominent with accent border.

**Permission prompt** — New `PermissionPrompt` component that checks notification + exact alarm permissions. Shows on first launch, deferred if user taps "Later". If user tries to create a reminder without permissions, the prompt appears again (bypasses deferral). Replaces the old `Alert.alert` approach.

**Reminder scheduling fix** — Reminders were getting cancelled immediately after creation. The edit sheet's `handleSave()` called `onClose()` (unmounting the component) BEFORE the deferred `InteractionManager` cancel+reschedule could complete. Fixed by: (1) removing auto-save on sheet dismiss, (2) moving cancel+reschedule to run synchronously before `onClose()`. Users now have an explicit Save button.

**Edit drawer changes** — Regenerate button shrunk from full-width blue to a small outlined pill. Added explicit "Save Changes" button (always active) and "Delete" button at the bottom.

**Navigation speed** — Cut animation durations: fade 100ms→50ms, slide 180ms→100ms.

**OpenRouter + Gemini** — Switched reminder parsing from GPT-4o-mini (direct OpenAI) to `google/gemini-3.1-flash-lite-preview` via OpenRouter. Whisper STT still on OpenAI (no transcription endpoint on OpenRouter). Convex env var `OPENROUTER_API_KEY` set.
