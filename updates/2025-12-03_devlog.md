### Issues Resolved
1. **Windows path length limit** - Build failed with "Filename longer than 260 characters"
   - Solution: Moved project from `C:\Users\...\voice-reminder\VoiceReminder` to `C:\Dev\VR`

2. **React 19 peer dependency conflicts** - npm install failed
   - Solution: Used `--legacy-peer-deps` flag for all npm installs

3. **Notifee maven repo missing** - Build failed finding `app.notifee:core`
   - Solution: Added `maven { url "$rootDir/../node_modules/@notifee/react-native/android/libs" }` to build.gradle

4. **Metro bundler connection** - Phone couldn't connect to localhost
   - Solution: Used `adb reverse tcp:8081 tcp:8081` for USB connection
