# Devlog - 2026-08-18

## Dock-vanish bug: caught live over Metro, fixed with an index-stream net - (09:00-14:00)

**Status**: ✅ Fixed + verified on device (18 opens / 18 releases, net caught 8 silent closes)

User repro: open/close the edit sheet 2-3 times fast and the bottom dock dies until app
restart — and other reminders stop opening too. Same single stuck state, not two bugs.

- No adb on iOS, so wired the iPhone dev client to local Metro over LAN and read the
  `[VR PERF]` chain live while the user reproduced. Cycle 7: `sheet_mount` →
  `onAnimate(-1→0)` → nothing, ever. Closing before the open animation settles parks the
  sheet at the closed position by gesture; `animateToPosition` early-returns
  (`position === animatedPosition`, bottom-sheet v5.2.7 BottomSheet.tsx:611) — no
  onAnimate, no onChange. `app/index.tsx:1180` renders the dock on `!editingReminder`,
  and only those callbacks ever cleared it. Every later tap fed the invisible sheet
  (no key, instance reused across reminder ids).
- Fix: `lib/sheetClose.ts` `crossedIntoClosed()` + a `useAnimatedReaction` on the sheet's
  `animatedIndex` — fires `onClose` on any downward crossing into closed, whatever the
  route. Wired into `EditReminderSheet` (new perf event `close_from_index_stream`) and
  `ComposerSheet` (same trap, weaker signal — it only had onChange). onAnimate fast path
  stays for instant dock reappearance.
- 7 unit tests (`__tests__/lib/sheetClose.test.ts`) incl. the snap-from-open silent path.
