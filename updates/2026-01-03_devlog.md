## Added Doze mode bypass for alarms - (06:14)

**Status**: ✅ Done

Android's Doze mode was potentially causing alarms to be delayed when the device was idle. Added `alarmManager: { allowWhileIdle: true }` to both trigger configurations.

**What this does:**
- Uses `setExactAndAllowWhileIdle()` Android API instead of standard `setExact()`
- System will wake up to fire alarms even in Doze mode
- Applies to both initial scheduling and recurring reminder rescheduling

Files:
- `lib/notifications.ts:120-126` - added alarmManager to initial trigger
- `lib/notifications.ts:253-259` - added alarmManager to recurring trigger

## Bottom sheet animation tuning - (12:30)

**Status**: ✅ Done

Extensive work on making the bottom sheet animation smooth and responsive. Went through multiple iterations:

**Attempts:**
1. ❌ Started with `sheetReady` state + `requestAnimationFrame` → caused two-click issue
2. ❌ Spring animation with `useBottomSheetSpringConfigs` → jittery/bouncy
3. ✅ Timing animation with `useBottomSheetTimingConfigs` → smooth!

**Final configuration:**
```tsx
const animationConfigs = useBottomSheetTimingConfigs({
  duration: 280,
  easing: Easing.out(Easing.cubic), // Smooth deceleration
});
```

**Other optimizations applied:**
- `enableDynamicSizing={false}` - skip sizing calculations
- Optimized backdrop with `pressBehavior="close"`
- `animateOnMount` enabled for smooth initial open
