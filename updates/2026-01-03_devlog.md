## Added Doze mode bypass for alarms - (06:14)

**Status**: ✅ Done

Android's Doze mode was potentially causing alarms to be delayed when the device was idle. Added `alarmManager: { allowWhileIdle: true }` to both trigger configurations.

**What this does:**
- Uses `setExactAndAllowWhileIdle()` Android API instead of standard `setExact()`
- System will wake up to fire alarms even in Doze mode
- Applies to both initial scheduling and recurring reminder rescheduling

Files:
- `lib/notifications.ts:120-126` - added alarmManager to initial trigger
- `lib/notifications.ts:253-259` - added alarmManager to recurring trigger

## Implemented alarm screen navigation - (06:28)

**Status**: 🔄 Testing

Added navigation to full-screen alarm UI when notification is delivered. The alarm screen shows Dismiss and Snooze buttons.

**How it works:**
- When notification fires (DELIVERED event), navigates to `/alarm` screen via deep link
- Alarm screen receives notification data via URL params
- Plays audio in loop + vibration pattern
- Dismiss/Snooze buttons stop audio & navigate back
