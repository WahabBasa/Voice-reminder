## Fixed timezone bug for relative time parsing - (12:10)

**Status**: ✅ Fixed

"Remind me in 2 minutes" was being scheduled for 8am instead of current time + 2 minutes.

**Root cause**: Device was sending UTC time (`2026-01-02T08:07:26.431Z`) but user is in UTC+4, so 12:07 local was parsed as 08:07.

**Fix**: 
1. App now sends local date and time separately (no UTC conversion)
2. Added relative time rules to GPT prompt so it knows how to calculate "in X minutes"
3. Added detailed logging to trace the full pipeline

Files:
- `app/index.tsx:162-175` - sends `deviceLocalDate` and `deviceLocalTime` instead of ISO timestamp
- `convex/actions.ts:207-244` - uses local time directly, added logging
- `convex/actions.ts:268-272` - added "IMPORTANT - Relative time rules" to GPT prompt
