## Performance pass + settings + cleanup - (23:38)

**Status**: ✅ Working (UI feels snappier)

App was starting to feel laggy when navigating (especially around creating/editing/deleting reminders). Did a performance-focused refactor based on Expo’s “reduce lag” best practices: virtualize lists, keep JS thread free during transitions, and bound local storage growth.

Main changes:
- Removed Calendar page completely (it was extra UI + more storage reads) and replaced the top “All” area with an `All / Completed` toggle on the home screen.
- Swapped the per-reminder options menu for a simple “checkbox” circle to mark reminders done (faster + less UI work).
- Standardized icons to Feather (cleaner line style, and avoids invalid icon-name warnings like `mic-outline` on Feather).
- Added a simple Settings page (just links to system notification settings + History + About/version).

Performance-specific changes:
- Home + History lists moved from `ScrollView` mapping to `SectionList` for virtualization.
- Deferred heavier work until after navigation/animations using `InteractionManager.runAfterInteractions()` (loading data on focus, scheduling notifications after screen transitions, Convex updates after closing edit).
- Made “Mark done” optimistic (UI updates instantly; AsyncStorage write happens in the background).
- Capped reminder history size so AsyncStorage JSON read/write doesn’t grow unbounded over time.
