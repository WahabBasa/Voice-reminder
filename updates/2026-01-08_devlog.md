## Fixed 'split of undefined' Error - (06:46)

**Status**: ✅ Fixed

Red box error appeared after snooze: `TypeError: Cannot read property 'split' of undefined`

**Root cause**: `lib/time.ts` functions `getDueTimestamp()` and `getNextTriggerTime()` called `.split()` on `schedule.time` without null checks. Some reminders had `time: undefined`.

**Fix**: Added defensive null checks at the start of both functions - if `time` is undefined, return current timestamp with a warning.

- `lib/time.ts:78-82` - getDueTimestamp null check
- `lib/time.ts:170-174` - getNextTriggerTime null check

## Fixed 'timestamp must be in future' Error - (07:02)

**Status**: ✅ Fixed

Another red box: `Error: notifee.createTriggerNotification(*) 'trigger.timestamp' date must be in the future.`

**Root cause**: When scheduling notifications, calculated trigger timestamp was sometimes in the past (e.g., alarm set for 7:00 AM but it's already 7:02 AM).

**Fix**: Added safety checks in `lib/notifications.ts` - if timestamp is in the past, adjust to "now + 5 seconds" so notification fires immediately rather than throwing.

- `lib/notifications.ts:120-127` - scheduleReminder safety check
- `lib/notifications.ts:234-241` - recurring reschedule safety check
