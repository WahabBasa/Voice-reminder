## Reminders page redesign - (07:15-09:00)

**Status**: ✅ Shipped, OTA group 7475d035 live

Spec `docs/specs/2026-09-08-reminders-page.md` — two Codex design rounds (gpt-6-astra, medium)
on the membership rules, then the user reshaped the layout to Android-alarms style:

- **Page 1 → "Reminders"**: flat list of every active reminder (`isReminderActive`, the cap's
  rule), sorted by next ring, no sections. Card line 1 = when it fires next ("Next in 4 hours",
  "Tomorrow · 7:00 am", "Next in 6 days", "Overdue · Sep 8 · 6:00 pm", "Rings again 3:52 pm");
  line 2 = pattern ("Every Mon, Wed · 9:00 am", "Daily · 9:00 pm", "Once · Sep 21 · 9:00 am").
  Tick circle only on cards due today/overdue; overdue one-offs get a red dot and stay listed
  (they still count toward the cap — hiding them was the OLD-118 confusion).
- **Days**: activity dots removed; one red dot on days with an overdue one-off; blue today mark
  independent of selection, selected day gets a neutral underline. MonthSheet same.

Edge cases Codex caught that changed the design: `getReminderNextDueTimestamp` drops the schedule
grid (multi-time/window reminders would mis-place) → resolver goes snooze → `nextGridOccurrence` →
legacy; ticking a repeater early still returned today's ring → reference = next-day start − 1 ms
(exact midnight would skip a 00:00 ring); snoozed-past-time one-offs landed in Overdue → snooze
wins; null grid must keep the card ("No next ring scheduled"); refresh on AppState active, not
just the 30 s tick; scroll a reconciled take's card into view once. Rejected as scope creep: i18n
layer, renaming "Completed today", DST/timezone-travel bounds, multi-ring completion semantics.

Files: `lib/remindersMembership.ts` (new, pure, 100% covered), `app/index.tsx` (flat FlatList,
unified refresh + snooze snapshot, scroll-on-reconcile, title), `components/ReminderListItem.tsx`
(`showCompletion`, `detail`, `overdueDot`), `components/days/{WeekStrip,MonthSheet,DaysPage}.tsx`,
`components/BottomBar.tsx` (a11y labels), `lib/time.ts` (`formatNextIn` lifted),
`components/OverdueSection.tsx` + activity-dot helpers deleted. Tests:
`__tests__/lib/remindersMembership.test.ts`, `__tests__/components/weekStrip.test.tsx`
(jest.config.js now discovers `.tsx` tests).

Review catch on Codex's build: `patternLine` for one-offs passed `nowMs = 0` → a date-less
one-off would print a 1970 date. Fixed to real clock and "Once · …" prefix.

Gates: tsc clean, **48 suites / 1420 tests**, thresholds green. Commit `4df51ac`. Manifest serves
