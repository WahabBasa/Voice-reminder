# es-MX UI translation: notes (2026-10-10)

Companion to `es-MX.json` (426 keys, same keys and order as `strings-en.json`). Follows `es-MX-style-guide.md`: tú, infinitive buttons, imperative hints, sentence case, Apple es_419 terms, "celular" in casual copy and "iPhone" in instructions and permissions, no Spain-only forms, no Mexico-only slang, no provider names. "Remi" and "Remi Pro" stay as they are.

**Validation (script, 2026-10-10):** 426/426 keys, same order; every `{placeholder}`, plural argument and `<link>`/`<b>` tag matches the English; every plural has `other`; ICU syntax parses. No "..." (all ellipses are the single `…` character).

## 1. Decisions

**Plurals.** CLDR `es` has `one`, `many` and `other`. `many` covers only exact millions ("1 000 000 de…"), which no Remi count reaches, and ICU falls back to `other` when a category is missing. So every plural carries `one` + `other` only. One-form-is-its-own-phrase applied where it reads better:
- `time.every.minutes` one = "Cada minuto"; `time.every.hours` one = "Cada hora"; `time.every.days` and `schedule.everyNDays` one = "Todos los días". This also fixes the English "Every 1 days" bug the inventory flags for `schedule.everyNDays`.
- `paywall.term.*` one = bare noun ("mes", "año"), so "cada {term}" gives "cada mes" / "cada 3 meses".
- Countdowns and steppers keep `#` in `one` ("Suena en 1 hora", "1 día"), as in English.
- `take.multiCreated`: English has only `other` (count ≥ 2). I added a `one` branch ("# recordatorio creado") as a safety net. Remove it if the structure must be identical.

**Gender and agreement.** Gender-neutral rewrites for the user: "¡Te damos la bienvenida a {product}!", "¿Quieres eliminar “{title}”?" (not "¿Estás seguro?"), "Hecha para quienes olvidan mucho", "Se enviará cuando abras Remi y tengas conexión" (avoids gendering Remi). Noun agreement: "Activo" (plan Pro), "Activadas" (notificaciones), "Ilimitados" (recordatorios), "Pro activado".

**Times.** `time.clock.am/pm` and `times.picker.am/pm` = "a.m." / "p.m.", what CLDR es_419 renders in abbreviated form. RAE prefers "a. m." / "p. m."; es_MX narrow forms use the spaced version. Pick whatever the device formatter renders so hand-built and Intl times match (guide §c).

**Weekdays.** Short: dom, lun, mar, mié, jue, vie, sáb (lowercase, no period, CLDR style). Narrow: L M M J V S D. Tuesday and Wednesday are both "M", the same kind of clash as the English T/T and S/S. CLDR base `es` uses "X" for Wednesday, but es_MX and Apple LatAm use "M". Better generated by Intl anyway.

**Language names** (`language.name.*`): lowercase, because both host strings place them mid-sentence: "Escuchando en {language}", "Remi aún no habla {language}". None of them is used as a standalone label in the current code. If one is ever shown alone (a picker row, a title), capitalize at render time. `settings.voiceLanguage.en` IS standalone (an alert button), so it is "Inglés" with a capital. Choices: "neerlandés" (CLDR/Apple) over "holandés"; "finlandés" over CLDR's "finés" (LatAm usage; switch if Apple's list says "finés"); "suajili" (RAE/CLDR); "tagalo"; "bengalí"; "noruego bokmål".

**Alarm buttons.** "Later" = **Posponer** (the alarm rings again, so it is a snooze; Apple's own term). "Done" = **Listo** (marks it done, not just a stop). Alternative for the AlarmKit stop button: "Detener" if the button only silences the alarm.

**Paywall legal.** Built from the guide's §d phrasing: "El pago se cargará a tu Cuenta de Apple al confirmar la compra", "se renueva automáticamente… hasta que la canceles", "dentro de las 24 horas previas", "al menos 24 horas antes de que termine el periodo actual", "periodo" (no accent) throughout. Every English clause is kept; nothing added. `{price}` comes only from the placeholder; no currency symbol is typed anywhere. Settings path is kept as in the English: "Configuración > Cuenta de Apple > Suscripciones". The guide's alternative is "Configuración > [tu nombre] > Suscripciones" (the actual iOS row shows the user's name). In the Settings alert (`settings.alert.manageFailed.message`) I used the more helpful "Configuración › tu nombre (Cuenta de Apple) › Suscripciones".

**Paywall CTA and caption.** `paywall.cta.trial` = "Probar {length} gratis" ("Probar 7 días gratis", 20 chars), using Apple's "%@ gratis" pattern instead of the longer "Iniciar prueba gratis de 7 días" (31). `paywall.caption.trial` = "{length} gratis, luego <b>{price}/{termShort}</b>." from the guide's short line. `termShort`: mes / año / sem / día (no periods, symbol style).

**Info.plist.** Both use "Remi" (the English AlarmKit text says "VoiceReminder") and "iPhone" for "phone", per guide rule 11. No provider named.

**App Store article.** "el App Store", as in Apple LatAm's badge ("Consíguelo en el App Store"). Some Mexican users say "la App Store"; low risk either way.

## 4. English source strings that look wrong or worth fixing

- `infoPlist.NSAlarmKitUsageDescription`: says "VoiceReminder", not "Remi". Translated with "Remi".
- `schedule.everyNDays` / `repeat.stepper.days`: inventory says the English prints "Every 1 days" at 1; the `one` branch in the catalog fixes it.
- `take.multiCreated`: plural with only `other`. Fine in ICU, but unusual; see §1.
- `settings.row.terms.subtitle`: "licence" (British) while the legal text uses US "canceled". Pick one spelling in English.
- `settings.alert.manageFailed.message` uses "›" and the paywall disclosures use ">". Pick one.
- `paywall.restore` ("Restore purchase", singular) vs `settings.row.restore` ("Restore purchases", plural) vs `paywall.legal.restore` ("Restore"). Translated faithfully ("Restaurar compra" / "Restaurar compras" / "Restaurar"); `paywall.error.alreadyOwned` points at "Restaurar compra" to match `paywall.restore`. Consider unifying on the plural.
- Title Case in some English toasts ("Purchase Complete", "Purchases Restored", "Subscription Expired", "Nothing to Restore", "Pro Activated!", "Delete Reminder", "Select Date", "New Recording", "Try Again") while their twins are sentence case. Spanish uses sentence case everywhere.
- `today.completed.header` "COMPLETE ({count})": "COMPLETED" would be the adjective. Translated as "TERMINADOS".
- `time.clock.am/pm` ("am") and `times.picker.am/pm` ("AM") differ in case for the same thing.
- `paywall.legal.disclosure.priced` repeats "{price} every {term}" twice; fine legally, a bit heavy.
- `common.error` as a bare alert title ("Error") is unfriendly in any language; the guide prefers "No se pudo…" titles.
- `pending.quickChoice.a11y` relies on lower-casing the chip label in code (`PendingTakeCard.tsx:260`). Spanish chip labels start with a capital ("En 1 hora"), so the code must lower-case or use separate a11y strings, otherwise VoiceOver reads "Recuérdamelo En 1 hora" (harmless when spoken).
