# Greek (el) UI translation review (2026-10-10)

Independent review of `el.json` against `strings-en.json` and `strings-inventory.md`. Every string was back-translated to English and compared with the source; the table lists every string changed.

**Verdict: SHIP**

- Careful translation: polite εσείς register, Apple-style nominal buttons (Διαγραφή, Αποστολή, Νέα δοκιμή), ASCII `;` question mark, «» quotes, gender-neutral rewrites, upper-case without tonos.
- Main change: «υπόμνηση/υπομνήσεις» (Apple's Reminders term) replaced everywhere by the everyday «υπενθύμιση/υπενθυμίσεις», per the orchestrator rule. All 8 inflected forms were mapped, including the double accent before the enclitic («υπενθύμισή σας», «υπενθύμισής σας»). 44 strings touched.
- Language names are lowercase neuter plurals that fit both carrier sentences («Ακρόαση στα αγγλικά», «Το Remi δεν μιλά ακόμη αγγλικά» / «…αυτή τη γλώσσα»).
- Paywall legal text is complete; passive «χρεώνεται» keeps Apple as the charging party.
- Overflow to check on device: `tabs.reminders` is now «Υπενθυμίσεις» (12 chars vs ~10). No shorter everyday word exists.

## Kept as is / notes for the owner

- Notifications = «Γνωστοποιήσεις» and alarm = «Ειδοποίηση» kept (Apple's split). Many Greeks say «ειδοποιήσεις» for notifications, but (a) the user has to find «Γνωστοποιήσεις» in iOS Settings to turn them on, and (b) AlarmKit's own system UI labels Remi's alarms «Ειδοποίηση», so swapping would collide with the alarm word. Consequence: `settings.row.notifications` reads «Γνωστοποιήσεις και ειδοποιήσεις». Owner decision if a fully everyday vocabulary is wanted (alarm would then need «ξυπνητήρι», which implies wake-up).
- `paywall.hero.default.*` «Μην ξεχνάτε. / Θυμηθείτε / στην ώρα.» turns "Forget less" into "Don't forget" for the ~12-char lines; kept. Closing headline keeps the literal «Ξεχνάτε λιγότερα.».
- `today.timeDraft.confirm` «Να μου θυμίσει» (14) kept: gender-free and natural.
- `pending.thatTime` «αυτή» only works inside «Η ώρα {time} πέρασε…»; that is its only use (lib/pendingCardContent.ts), so kept.
- Over-length vs inventory, no natural shorter form: `tabs.reminders` «Υπενθυμίσεις» 12/~10, `today.header.getPro` «Απόκτηση Pro» 12/~10, `permission.enable` «Ενεργοποίηση» 12/~10, `paywall.card.badge` «ΚΑΛΥΤΕΡΗ ΤΙΜΗ» 13/~12, `paywall.cta.trial` with 7 days 25/~24. Verify on device.
- `aiConsent.allow` «Αποδοχή» instead of Apple's longer «Να επιτρέπεται»: kept for the ~10 limit.
